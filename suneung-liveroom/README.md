# 수능고등학교 (가상 수능 체험)

3층 × 교실 5개짜리 3D 학교. 입장 → 닉네임 → 클릭으로 이동 → 책상에 앉으면 1인칭으로 시험지·OMR → 쉬는 시간에만 채팅 → 칠판에 포스트잇.

## 켜는 법 (Windows)
1. 압축을 풀고 `start.bat` 더블클릭 (처음엔 1~2분)
2. 크롬에서 http://localhost:3000
3. 끄려면 검은 창 닫기 (Ctrl+C 누르지 마세요)

## 시간표 (모두에게 동일, 약 15분 주기)
입실 → 국어 → 쉬는시간 → 수학 → 점심 → 영어 → 쉬는시간 → 한국사 → 성적·자유시간 (실제 수능 순서, 한 바퀴 16분 30초. 교실 시계는 수능 날 시각으로 흘러가요). 숫자는 `shared/schedule.js`에서 바꿀 수 있어요.

## 폴더
- client/ 화면(3D) · server/ 실시간 서버 · shared/ 둘이 같이 쓰는 규칙(시간표·좌석·상수)
- 포스트잇은 server/data/postits.json 에 저장돼요.

## 배포 전 꼭 확인
- 채팅·포스트잇 욕설/비방 관리(지금은 길이·속도 제한만 있음)
- 실제 평가원 기출을 쓰려면 저작권 이용 조건 확인 (지금 문제 10개는 직접 만든 것)
- Render 무료 플랜은 잠들고 파일이 초기화될 수 있음

## 운영자(만든 사람) 입장
- 입장 화면 아래 '운영자 입장'을 누르고 코드를 넣으면 👑 금색 닉네임으로 들어가요. 일반 사용자는 '운영자·관리자·제작자' 같은 닉네임을 못 써요.
- 기본 코드는 `suneung-owner-2026` 이에요. **배포할 땐 꼭 바꾸세요**: 서버 환경변수 `ADMIN_CODE` (표시 이름은 `ADMIN_NAME`, 기본 '제작자').
- 오류가 나면 화면 위에 빨간 상자가 떠요. 캡처해서 보내주세요.

## 급식실 · 수험표 · 안내방송
- 1층 맨 끝(오른쪽) 교실은 급식실이에요. 점심시간에 줄 서는 선 안쪽으로 들어가면 급식 아주머니가 식판을 주고, 🍚 먹기 버튼으로 식사해요.
- 수험표(수험번호·문형)는 입장 때 한 번 보이고, 🎫 버튼으로 다시 볼 수 있어요. 문형(홀/짝수형)은 분위기용 표시예요.
- 안내방송(입실·시작·종료 30초 전·종료령·점심)은 채팅창과 화면 알림, 브라우저 음성으로 나와요.
